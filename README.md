## 📗 Book Vibe


**Book Vibe** is a modern book discovery web application where readers can explore a collection of books, view detailed information, and organize their favorite books into personalized Read Lists and Wishlists.


**Live Website |** [Book Vibe](https://book-vibe-bookshelf.surge.sh/)


---




### || Project Overview

Book Vibe is a book management platform that provides an organized space for readers to discover books and manage their reading preferences. Users can explore book collections, access detailed book information, and maintain separate Read Lists and Wishlists. The application offers a smooth browsing experience with dynamic sorting, persistent data storage, and a responsive user interface.

Built with **React and modern frontend technologies**, the project demonstrates practical implementation of component-based architecture, state management, client-side routing, and dynamic data handling.

---


### ✨ Core Functionalities

- **Explore Books** — Browse a diverse collection of books with essential information.
- **Detailed Book View** — Access comprehensive information about each book.
- **Reading Collection** — Maintain a personalized collection of books marked as read.
- **Wishlist Management** — Save interesting books for future reading.
- **Smart Sorting** — Organize books based on page count and ratings.
- **Duplicate Validation** — Prevent duplicate entries across reading collections.
- **Persistent Storage** — Retain saved Read List data using browser localStorage.
- **Interactive Navigation** — Navigate seamlessly between pages and book collections.
- **Responsive Interface** — Enjoy a consistent experience across mobile, tablet, and desktop devices.

### 🔌 Data Integration

The project uses a local `booksData.json` file to store book information. Data is fetched using JavaScript's `fetch()` and handled with **Promises, async/await, React's `use()`, and Suspense** to display books dynamically.

### || Reading List Management

The application uses separate lists to manage reading preferences.

- `map()` — Render books dynamically.
- `find()` — Check whether a book already exists in a list.
- `filter()` — Filter books based on specific conditions.
- `sort()` — Sort books by pages and ratings.
- `useState()` — Manage Read List and Wishlist states.
- `useContext()` — Share book data across components.
- `localStorage` — Persist Read List data in the browser.
- `useEffect()` — Handle sorting updates when dependencies change.
